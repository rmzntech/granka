# Проекты и правила

Четыре слоя, от общего к частному:

| Слой | Файл | Для чего |
|---|---|---|
| Системный промпт | `~/.granka/SYSTEM.md` | управляется приложением, не редактируется |
| Правила | `~/.granka/AGENTS.md` | предпочтения и запреты для всех проектов |
| Проект | инструкции проекта в UI | конвенции конкретной папки: сборка, тесты, стиль |

## Что писать в инструкции проекта

- команды сборки/тестов/линтера, которые здесь приняты;
- что нельзя трогать (прод-конфиги, секреты, CI);
- особые соглашения (структура папок, стиль коммитов).

Не дублируй общие вещи — они уже в AGENTS.md и системном промпте.

## Что писать в AGENTS.md

Короткие постоянные факты и предпочтения: язык общения, стек, стиль ответов,
чего никогда не делать. Не складывай туда содержимое кода — для этого есть
файлы проекта.

## Проверка

После правки правил начни новую сессию или нажми «сжать»: правила применяются
при создании сессии.
