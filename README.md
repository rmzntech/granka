# granka

**Локальный десктоп-клиент для агента [Pi](https://pi.dev).**  
Чат с агентом, который читает и правит файлы, работает с PDF и DOCX, ищет в вебе
без API-ключей и держит контекст в порядке — всё на вашей машине.

Electron 45 · Pi SDK · без облака · без собственного сервера

---

## Зачем это

Терминальные агенты мощные, но жить в них неудобно: нет истории по проектам,
не видно, что агент делал, а настройки размазаны по флагам. granka оборачивает
Pi SDK в обычное приложение:

- **чат** с потовым ответом, markdown-таблицами и списком действий агента;
- **проекты** — папка, свой `AGENTS.md`, своя модель и уровень мышления;
- **документы** — читает и создаёт PDF/DOCX с оформлением;
- **свои инструменты** — план, вопрос пользователю, веб без ключей, подагенты;
- **тишина** — тёмная/светлая тема, 13 палитр, аккуратная типографика.

Все данные лежат в `~/.granka`. Наружу уходят только запросы к выбранной модели.

## Возможности

| Группа | Что есть |
|---|---|
| **Чат** | стриминг с троттлингом по кадру, markdown (таблицы GFM, цитаты, код), копирование ответа и кода, цитирование, повтор запроса, стоп/очередь сообщений, поиск по истории чатов |
| **Проекты** | проект = папка + проектный `AGENTS.md` + модель + thinking; чаты жёстко привязаны к проекту, перенос чата в другой проект из контекстного меню |
| **Правила** | системный промпт управляется приложением (только чтение), глобальный `~/.granka/AGENTS.md`, проектный `<папка>/AGENTS.md` |
| **Инструменты** | `todo_write` (план в композере), `ask_user` (модальный вопрос с вариантами), `web_search`/`web_fetch` (DuckDuckGo Lite, Википедия, GitHub, Hacker News — без ключей), `task` (подагенты) |
| **Подагенты** | `explore` — код, `research` — внешние факты, `review` — дефекты в диффе, `plan` — план работ, `general` — разбор |
| **Документы** | `doc_outline`, `doc_read`, `doc_search`, `doc_create`, `doc_edit`, `doc_format` для PDF и DOCX, с оформлением: шрифт, кегль, поля, колонтитулы, таблицы, акцентный цвет |
| **Вложения** | drag&drop, вставка из буфера, скрепка; изображения уходят в модель, документы читаются инструментами |
| **Настройки** | 7 разделов: общие, модель, агент, инструменты, оформление, шрифты, скиллы; отдельное окно |
| **Скиллы** | 6 встроенных (`granka-skill-creator`, `granka-docs`, `granka-subagents`, `granka-tokens`, `granka-web`, `granka-projects`) + свои из `~/.granka/skills` |
| **Аналитика** | расход токенов и стоимость по дням и моделям |
| **Контекст** | компакция с настройкой резерва, длинный кэш промпта, лимит вывода инструментов |

## Быстрый старт

```bash
git clone git@github.com:rmzntech/granka.git
cd granka
npm ci
npm start
```

Нужен Node.js 22+ и ключ [OpenRouter](https://openrouter.ai). Ключ вводится
в настройках (`Ctrl/Cmd + ,`) при первом запуске — он сохраняется только локально.

## Установка

**Arch Linux** — пакет собирается локально и кладётся в свой pacman-репозиторий:

```bash
./packaging/build-arch.sh      # пакет + обновление ~/pacman-myapp
./packaging/install-arch.sh    # установка (sudo запускает пользователь)
```

Пакет зависит от системного `electron` (≈25 МБ), данные остаются в `~/.granka`.

**Windows** — portable exe без установки:

```bash
electron-builder --win portable --publish never
# → dist/granka-<version>-portable.exe
```

Кросс-сборка требует `wine` и сеть для загрузки Electron/NSIS.

**macOS** — `npm run dist:mac` (только на macOS; окно использует нативные светофоры).

## Данные

| Путь | Что внутри |
|---|---|
| `~/.granka/granka.json` | настройки (модель, тема, шрифты, лимиты) |
| `~/.granka/SYSTEM.md` | системный промпт приложения (обновляется с версией) |
| `~/.granka/AGENTS.md` | ваши глобальные правила |
| `~/.granka/skills/`, `prompts/` | скиллы и шаблоны команд |
| `~/.granka/attachments/` | копии вложений |
| `~/.granka/sessions/` | история диалогов (JSONL) |
| `~/.granka/session-projects.json` | привязка чатов к проектам |
| `~/.granka/stats.jsonl` | токены и стоимость запросов |

Удаление папки сбрасывает приложение к первому запуску.

## Устройство репозитория

```
electron/          main-процесс: окна, IPC, агент, инструменты, документы, подагенты
  agent.mjs        сессии, конфиг, проекты, статистика, компакция
  tools.mjs        todo_write, ask_user, web_search, web_fetch, task
  docs.mjs         PDF/DOCX: чтение, создание, правка, оформление
  subagents.mjs    роли подагентов и их промпты
  skills/          встроенные скиллы
renderer/          интерфейс: чат, проекты, настройки, темы, шрифты
packaging/         PKGBUILD, desktop-файл, скрипты сборки и установки
test/              тесты логики и интерфейса
build/             иконки для сборки (из icons.svg)
AGENTS.md          заметки для ИИ-агентов, работающих в этом репозитории
```

## Разработка

```bash
npm test              # логика: smoke, markdown, инструменты, документы
npm run test:ui       # главное окно (Electron, скрытое)
npm run test:settings # окно настроек
npm run test:theme    # тема применяется во всех окнах
npm run test:all
```

Правила проекта — в [`AGENTS.md`](AGENTS.md): минимальные диффы, только чистый JS
в зависимостях, пакеты собираются **только по прямой просьбе** и только для
запрошенной платформы.
